# 五层「二结局」问询（2026-10-31 玩家新增，强制）

## 什么时候问

**层数 = 五层（卡德霍之颅）+ 左区读到 3 个「命运所指」** → 本局拿了**二结局相关藏品**，
这三个节点只在这种情况下才会在五层出现。此时**求解之前必须先问**：

> **Q：本局是否打二结局？**

还没问就调 `route.py` / `observe.py` / `build_scenario.py`，工具直接 `❌ exit 2`，
不会先按旧口径算一版。同一局五层的滚动重算沿用答案（scenario 里的 `second_ending`）。

判据是**左区**（x ≤ 左区最右列）的 3 个命运所指，**不含右区那 1 个**（五层右区固定 1 个命运所指，
见 `14-五层全图.md`）。没有这 3 个 = 普通五层，不适用本题。

## 三个命运所指分别是什么

| 位置 | 右上角 | 进入后 | 规划处理 |
|---|---|---|---|
| 左区 · **无徽章** ×2 | 无白圈 | 获得 **1 件随机收藏品** | 价值 = 本层「**得偿所愿 − 1**」（五层 **7 分**），可正常进路线 |
| 左区 · **有徽章** ×1 | 白圈徽章 | 进入**二结局关卡** | **本层终点**（二结局=要）／**-99 硬避**（=不要） |
| 右区 · 命运所指 | 无 | **零件箱所有加工品剩余次数强制→1**（含之后获取的） | 二结局=要 → **必走点，尽量排最后**；=不要 → **本层终点** |

> **为什么「得偿所愿 − 1」**：得偿所愿是「两件收藏品里**自己选 1 件**」；
> 命运所指只给 1 件**随机**收藏品、没有选择权，所以比得偿所愿少 1 分。五层得偿所愿 8 → **7**。
> 数值真源：`rules.second_fate_random_value(layer)`（跟着层价表走，别在别处写死 7）。

## 分支总表

| 回答 | 左区无徽章命运所指 | 左区带徽章命运所指 | 右区命运所指 | 本层最后一步 | 求解方式 |
|---|---|---|---|---|---|
| **不要** | 各 7 分（正常进路线） | **-99**（不进入，避免触发二结局关卡） | 终点（`final`） | **右区命运所指** | 分阶段照旧（右区预留 5 点） |
| **要** | 各 7 分（正常进路线） | **终点**（`final`，0 分） | **必走（`must`）+ 次数钳制（`clamp_items_at`）** | **左区带徽章那个** | **自动整体求解**（终点在左区，分阶段表达不了「先进右区、再回左区收尾」） |

## 二结局 = 要：两条硬约束

### ① 右区命运所指是必走点，且「尽量排最后」

进入右区命运所指后，**零件箱里所有加工品的剩余次数强制变成 1 —— 包括之后获取的加工品**。
所以它越晚进越值钱：早进去会把后面的跳跃预算砍掉。

这不是口头偏好，是**真的进搜索**的约束：
scenario 写 `"clamp_items_at": [[13,3]]`，求解器往这格落的那一步把状态里的 `items` 全部 `min(1)`
（`route_solver.Solver._clamp_after`），于是「先扫右边 → 再进它 → 最后只跳一步」自然成为最优。
输出里这一步会带 `← 二结局：进入后加工品次数强制→1`。

> ⚠️ **别把它写进 `values` 拉高/压低就算完成**：价值是 0，真正起作用的是「次数被砍」这条状态转移。
> 只靠「同分优先」或分值惩罚，都会出现「早进还更省」的假最优。

### ② 最后一步 = 左区带徽章的命运所指

- 它是**非作战节点**：**老妈妈的融雪**（任意非作战）可以直落；**结构性原理**（任意节点）也行。
- **只有直线/邻格件不行**：引擎（相邻 8 格）、假肢（相邻 8 格）、外骨骼（直线 3 格内）、
  轮子（直线 2 格内）、方向盘（同行/同列）——从右区到左区那一步基本都够不着，
  除非最后一步的几何恰好同列/同排（工具会自己判断，**不要人工许愿**）。
- 没有全图移动件 → 这一步走不到，工具**如实 ❌**（`无可行解`），不要硬凑一条假路线。

### 次序与 AP

典型形态（**8 点行动力 = 险路尽头；追猎 7 点**，6 件位移件）：`左区铺垫 → 跳进右区 → 清右区 → 进右区命运所指 → 全图件跳左区带徽章命运所指`。
右区命运所指**必须排在最后一步之前**（它是钳制点，排在最后一步会被 `final` 抢先收束），
但它**不必是倒数第二步**——只要之后不再需要多件跳跃件就行（工具按分值自己权衡）。

## 命令与参数

> 五层基础 AP：**追猎 7 / 险路尽头 8**。下面示例按险路尽头口径（`--ap 8`）；全程追猎把 `--ap` 改成 7。

```bash
# 五层 · 打二结局（带徽章那个自动从徽章识别；认不出就手报）
python tools/route.py 截图 --layer 5 --config L6 --ap 8 \
    --second-ending 要 --items "标准引擎:3;结构性原理:1" --max-time 300

# 五层 · 不打二结局（终点=右区命运所指）
python tools/route.py 截图 --layer 5 --config L6 --ap 8 --second-ending 不要 --items "..."

# 徽章检测失败/认错时锁定入口坐标
python tools/route.py 截图 --layer 5 --config L6 --ap 8 \
    --second-ending 要 --second-ending-node 3,1 --items "..."
```

- 参数：`--second-ending 要|不要`；`--second-ending-node c,r`（可选，手报带徽章那个）。
- 只用五层：别的层传了直接判错（`rules.layer5_scope_errors`）。
- `observe.py` 同样透传；它自己也会按「左区 3 个命运所指」提前拦一次（exit 2）。
- 滚动重算：答案落在 scenario 的 `second_ending` / `second_ending_node` / `clamp_items_at`，不必重问。

## 与终点模式的关系

**二结局问询优先于终点模式**（`--end-mode`）：

- `全程追猎`：本来五层终点就是「命运所指坐标」——出现 3 个命运所指时按二结局分支选**哪**一个。
- `险路尽头`：本来要求最后一步落在**险路恶敌**——但出现这 3 个命运所指时，本层终点改由二结局决定，
  工具会打一行「本层终点改由二结局决定（五层 3 个命运所指优先于终点模式「险路恶敌」）」。
- 只有**没有**这 3 个命运所指的普通五层，才继续按终点模式收尾。

## 常见错误

| 错误 | 后果 | 正确判据 |
|---|---|---|
| 看到 3 个命运所指不问，直接按旧口径给路线 | 打二结局的局会把终点定错（右区 vs 左区），少打一次 BOSS | 先问；没答 exit 2 |
| 把右区命运所指当成「普通 0 分节点」 | 早进去 → 后面跳跃件全变 1 次，路线执行不了 | `must` + `clamp_items_at`，并尽量排最后 |
| 二结局=不要 却把带徽章的 (3,1) 当 0 分中继 | 一进去就触发二结局关卡，本局路线报废 | 带徽章那个在「不要」分支按 **-99 硬避** |
| 把无徽章命运所指按 8 分（得偿所愿原价） | 高估 1 分/格，可能挤掉更值的格 | **得偿所愿 − 1 = 7** |
| 最后一步用引擎/方向盘跳左区 | 几何够不着（右区到左区跨 8+ 列） | 必须全图件（融雪 / 结构性原理）；没有就如实 ❌ |
| 二结局=要 还走分阶段求解 | 左区终点 + 右区必走点被拆到两段，必然漏一头 | 工具已自动切整体求解（终点在左区时） |
