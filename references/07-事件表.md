## 一·附：狭路相逢的三档

狭路相逢进入后有**左、中、右三档**，三档都送 **2 张招募券**：

| 档 | 除招募券外 | 特点 |
|---|---|---|
| **左档** | 1 个 **N / R** 稀有度零件 | 最差 |
| **中档** | 1 个中档零件：**浪花 / 雾滚草 / R 零件 / SR 零件**（不含笼控器） | 上限高（可出 SR），下限低（浪花、雾滚草） |
| **右档** | 1 件 **8 或 12 价值**的藏品 | **确定收益**，8–12 当量 |

### 三档的取舍

**玩家实战口径：固定选「中档」。**

| 对比 | 结论 |
|---|---|
| 左档 | 无条件最差，不选 |
| **中档** | **实战默认选它** |
| 右档 | 不选（确定但只是即时藏品） |

**为什么中档优于右档**（这个理由比"赌 SR"更本质）：

> **中档给的是「可增值资产」（自然物），右档给的是「一次性藏品」。**

浪花、雾滚草 买入价 4–6，养到最后能到 20–30；而右档那件 8–12 的藏品是死的。
在"资产 > 现金"的经济结构里，中档长期更优，SR 尾部只是附加惊喜。

所以狭路相逢的规划价值可以按固定公式算：

```
中档期望 ≈ 11 当量（含自然物成长）
+ 回声玉米联动 +6（若带回声玉米）
```

### 一个此前漏掉的联动

三档都给 **2 张招募券** → **招募 2 次干员** → 喂**回声玉米**（每次招募估价 +3），一次狭路相逢 = **回声玉米 +6**。

所以带回声玉米时，狭路相逢的价值要再加一档。



## 二·附：会进入战斗的事件

掉落表里的「事件普通 / 事件紧急」，指的是**不期而遇中会进入战斗的那类事件**。

| 事件 | 层 | 战斗档位 |
|---|---|---|
| **思乡心切** | 一～二层 | **仅普通作战** |
| **划算买卖** | 二～三层 | **仅普通作战** |
| **鸭托邦** | 三～四层 | **普通 / 紧急 二选一** |
| **传奇团伙** | 四～六层 | **普通 / 紧急 二选一** |
| **湖中仙女** | 三～五层 | **普通 / 紧急 二选一** |

**掉落**：事件里的战斗 **100% 掉 1 个零件**（普通档 N/R；紧急档 N/R/SR），另加战斗本身的藏品收益。

### 战斗事件的必定掉落（可精确定价）

| 事件 | 层 | 普通档 | 紧急档 | 紧急档增益 |
|---|---|---|---|---|
| 思乡心切 | 一～二层 | **1 藏品** | — | — |
| 划算买卖 | 二～三层 | **3 藏品** | — | — |
| 鸭托邦 | 三～四层 | **1 藏品** | **3 藏品** | **+2 件（约 +16 当量）** |
| **传奇团伙** | 四～六层 | **3 藏品** | **5 藏品** | **+2 件（约 +16 当量）**；**持有源石锭 < 50 时只能打普通** |
| 湖中仙女 | 三～五层 | 1 藏品 | **1 个 16 价值藏品** | 约 +5 当量（且需 3 源石锭成本） |

按「低级藏品 = 8、高级 = 16」折算成源石锭当量：

| 事件档位 | 当量 | 对比 |
|---|---|---|
| **传奇团伙·紧急（5 件）** | **≈ 40** | **单点最高，超过右区紧急作战（24–32）** |
| 划算买卖·普通（3 件） | ≈ 24 | 二层性价比之王（仅 1 AP） |
| 传奇团伙·普通（3 件） | ≈ 24 | |
| 鸭托邦·紧急（3 件） | ≈ 24 | |
| 湖中仙女·紧急（16 价值） | 16（净 ≈13） | 事件里最弱的一档 |
| 思乡心切·普通（1 件） | ≈ 8 | |
| 鸭托邦·普通（1 件） | ≈ 8 | |
| 湖中仙女·普通（1 件） | ≈ 8 | |

### 三条结论

1. **传奇团伙是四～六层的头号事件**：源石锭 ≥ 50 时 5 件藏品（≈40 当量），不足 50 则降为 3 件（≈24 当量）。
   **所以「源石锭 50」是一道门槛，价值约 16 当量（2 件藏品）。** 到四层时若能保住 50，等于提前锁定一份礼物。
2. **划算买卖是二层的隐藏王牌**：仅 1 点行动力换 3 件藏品（≈24 当量），仅次于树根。二层只有 **5（追猎）/6（险路尽头）** 点行动力，它是必抢项。
3. **「二选一」不必一律选紧急**：
   - 鸭托邦、传奇团伙：紧急档多 2 件藏品（+16 当量）→ **必选紧急**
   - 湖中仙女：紧急档只多约 5 当量，还要付 3 源石锭成本 → **前期源石锭紧时选普通也无妨**



### 由此得出的判断

> **不期而遇 = 1 点行动力，换「事件收益 + 一场必掉零件的战斗」。**
> 而直接走到一个作战节点也是 1 点行动力，只换「一场战斗」。

所以**会进战斗的不期而遇，单位行动力收益严格高于普通作战节点**。它同时给三样：

① 推进／清空事件池
② 一场 100% 掉零件的战斗（含 8–16 藏品）
③ 喂「作战类」自然物（血蕈、恋心草、霜晶树）

**操作规则**：三类「可二选一」的事件（鸭托邦、传奇团伙、湖中仙女）——**一律选紧急档**。
理由：紧急档 8–16 藏品、必掉零件、还能出 SR；代价只是战斗难度，而作战默认打得过。

## 二、追忆的正确获取方式（已修正）

**没有前置钥匙**。「愈创之心」触发后，三个选项中任选一个即可：

| 支付方式 | 代价 |
|---|---|
| A | 消耗 **3 点行动力** |
| B | 消耗 **随机 2 件加工品** |
| C | 失去 **源私钥** |

**支付建议**：

- **默认选 A（3 AP）**：确定成本。四层 **7（追猎）/8（险路尽头）** 点里付 3 点，换来新层 7–8 点 + 树根，净 +4 AP 加一棵树根。
- **选 B 的条件**：手上恰好一堆垃圾件（剩 1 次的报废件），且结构性原理／背包已用完。
- **选 C 的条件**：身上刚好有源私钥且无其他用途 —— 但源私钥只来自「安眠一隅」（可忽略），所以实际很少出现。

## 三、不期而遇的期望值：不是纯赚，是彩票

**正向下行都有**：

| 方向 | 事件 | 量级 |
|---|---|---|
| **大赚** | 沉重的契约 | **+5 行动力**（代价半血） |
| **大赚** | 血衣之下 | 3 件藏品选 1 |
| 赚 | 撬动杠杆 / 湖中仙女 / 洞中宝 | 藏品、珍贵藏品 |
| 中性 | 货从口出 | 花源石锭买加工品 |
| **纯亏** | **呼吸的红苔** | **−1 AP，无收益** |
| 亏（条件） | 传奇团伙 | 可能失去一半源石锭 |

**结论**：

> 不期而遇**期望为正**（有一个 +5AP 的重磅事件），所以**顺路必进**；
> 但存在 −1 AP 的纯亏事件，且结果不可控 → **不值得为它专门绕远路**。

这正好解释了为什么实战里你觉得"顺路进"是对的、"特意绕"是不对的。

## 四、笼控器：套利品，但会污染事件池

| 项 | 值 |
|---|---|
| 获取 | 「沉眠之屋」（二层）：花 **2 血量** 或 **8 源石锭** |
| 主要用途 | **在行商卖掉，得 16 源石锭** |
| **隐性代价** | **它会解锁「呼吸的红苔」进入事件池** → 此后每次不期而遇都可能抽到「−1 AP 零收益」 |

**套利账**：

| 支付方式 | 净收益 |
|---|---|
| 花 8 源石锭 → 卖 16 | **+8 源石锭** |
| 花 2 血量 → 卖 16 | 16 源石锭，代价 2 血 |

> 16 源石锭 = **1 件高级藏品** = 右区打一次作战的收益。所以笼控器本身很值。
> 但它换来了一个纯亏事件进池 —— **买不买，取决于你的血量与源石锭状态**，不是无脑买。

## 五、藏品与源石锭的汇率（定价基准）

| 品类 | 价值 |
|---|---|
| 低级藏品 | **8 源石锭** |
| 中级藏品 | **12 源石锭** |
| **高级藏品** | **16 源石锭**（右区每个作战产出 1 个） |
| 笼控器 | 16 源石锭 |

## 六、要不要经营「50 源石锭」这道门槛？

门槛价值 = 40 − 24 = **16 当量（约 2 件藏品 = 16 源石锭）**。

但它是**概率事件**，所以要乘以遇到传奇团伙的概率：

| 每层遇到概率 | 门槛的期权价值 |
|---|---|
| 1/6 | ≈ 2.7 当量 |
| 1/3 | ≈ 5.3 当量 |

**结论：不值得刻意经营。**

- 平时**不必为了凑 50 而克制购买**——期权价值只有几当量，而一件加工品动辄值 4 源石锭以上。
- 真遇到时也**不要卖自然物去凑**：四层卖 2 件自然物换 16 当量，却损失约 72 的后续增值。
- **正确做法：源石锭够 50 就白赚 16 当量；不够就打普通档（24 当量），一样是全场第一梯队。**

自然物的卖出时机，只由"五层清估值"决定，不为单个事件服务。
