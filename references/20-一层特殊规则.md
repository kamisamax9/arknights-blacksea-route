# 一层特殊规则（最容易被忽略）
### 一层**默认没有理想源（树根）**

- **不要假设一层有树根**，也不要为了「可能有树根」预留行动力或改写路线。
- 一层的 AP 就是 **6 点基础**，没有 +2。
- 若某局确有理想源，**玩家会主动说**；没说就按没有处理。
  （2026-10-29 起这个「默认没有」与**分队模式无关**：N16文明开化、普通分队两种模式下一层都如此。）
- **有理想源时，它占用全层唯一的紧急作战名额** → 其余「未知的凶戾」= **普通作战 = 3.0 确定性**
  （与二层同构，见 `03-节点收益.md` 一·附）。不要再给凶戾记 3–5 的浮动。
  打它的收益**按分队模式算**：N16文明开化 = 15 分 + 2 AP；普通分队 = 9 分（=紧急作战）、无 +2。
- 二~六层才需要开口就问树根坐标（见开局报点清单；普通分队模式二~六层也不强制报，不报=无）。

### 一层开局零件箱固定 **2/12 = 2 个种子**

- 每局进一层都自带 **2 个种子**（占 2 格）。**它不是加工品，更不是位移件。**
- 所以「零件箱 2/12」是**默认状态**：**不要据此推断能不能跳，也不要再问**（玩家口径 2026-10-25）。
- 判断能不能跳，只看玩家报的加工品清单（如「1 鸣笛、1 结构性原理」）。

- **一层诡意行商位置是确定的**（按构型，不是随机）：构型1/2 → **(3,1)**；构型3 → **(1,2)** 与 **(4,1)** 各一个。
  它给 **+12 源石锭**，是一层最重要的经济来源，**必须排进主线**，不能当盲盒。
- 一层只有 8 类节点：作战、紧急作战、不期而遇、得偿所愿、诡意行商、秘境行商、**险路小径**、**险路尽头**。
- **没有**曲折密道、羽瞰点、误入奇境、狭路相逢、失与得、应急助力、安全的角落、居民据点。
- 「未知的诡秘」= 不期而遇 / 得偿所愿 / 诡意行商 / 秘境行商 / **险路小径** → **4 好 + 1 空**。
  → **险路小径 = 0 分、可进可出**（等同空节点），所以一层诡秘**可以无脑进**，最差只损失 2 分的期望值。
  → **险路尽头模式**下它升级：与尽头**同分值**（一层两者都 0）且是**最后一步候选**（软终点，仍可作中继）。
- 「未知的凶戾」= 作战 / 紧急作战（一层无居民据点）。
- 一层诡意行商：可获 **+12 源石锭**，且只买加工品、不买收藏品 → 它是**进账节点**。
- **险路小径不是默认点亮的**，它显示为「未知的诡秘」；固定点亮的只有曲折密道、羽瞰点、流窜居民、命运所指、险路尽头（只亮 1 个）、险路恶敌。
