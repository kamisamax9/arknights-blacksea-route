> **证据等级：C｜形状表** — 右区按 3 构型的格数/形状查表；形状对不上或多解时工具回退四邻接，
> 并在判词里打 ⚠️（「右区边表未验证」）。

> **右区只在「已获取四结局前置藏品」时存在**；未获取时本层只有左区（x 0–6，居中），
> 不预留 AP、右区必走点/收益失效，见 `25-右区有无.md`。

> **旧版「三层右区只有一个布局」作废。** 右区实际有 **3 种构型**，且整体会**上下浮动**。

> **工具链（2026-11-02）**：`build_scenario.right_zone()` 直接解析本节的三个形状表（`构型N（M 节点）` 标题 + `边：` 行）来连右区边，**不再用四邻接假设**。改这里的格子/边 = 改工具行为，改完跑 `selftest_solver.py`。

## 一、右区：3 构型 × 3 个纵向位置

**规则（玩家口径）**：三种构型的**形状固定**，但右区位置会上下变化——**左上角在 (8,4)、(8,3)、(8,2) 之间随机**，其余节点随之平移。

所以实际布局有 **3 × 3 = 9 种**。下表用 **Y = 左上角 y 坐标** 参数化。

### 构型1（7 节点）

```
y=Y      (8,Y) ─ (9,Y) ─ (10,Y)
           │       │        │
y=Y-1    (8,Y-1) (9,Y-1) (10,Y-1)
                     │
y=Y-2              (9,Y-2)
```

边：`(8,Y)-(9,Y)`、`(9,Y)-(10,Y)`、`(8,Y-1)-(9,Y-1)`、`(9,Y-1)-(10,Y-1)`、`(8,Y)-(8,Y-1)`、`(10,Y)-(10,Y-1)`、`(9,Y-2)-(9,Y-1)`

### 构型2（6 节点）

```
y=Y      (8,Y) ─ (9,Y)
                     │
y=Y-1    (8,Y-1) (9,Y-1) ─ (10,Y-1)
                     │
y=Y-2              (9,Y-2)
```

边：`(8,Y)-(9,Y)`、`(9,Y)-(9,Y-1)`、`(8,Y-1)-(9,Y-1)`、`(9,Y-1)-(10,Y-1)`、`(9,Y-1)-(9,Y-2)`

### 构型3（8 节点）

```
y=Y      (8,Y) ─ (9,Y) ─ (10,Y)
           │                │
y=Y-1    (8,Y-1)  (9,Y-1) — (10,Y-1)
           │
y=Y-2    (8,Y-2) (9,Y-2)
```

边：`(8,Y)-(9,Y)`、`(9,Y)-(10,Y)`、`(10,Y)-(10,Y-1)`、`(9,Y-1)-(10,Y-1)`、`(8,Y)-(8,Y-1)`、`(8,Y-1)-(8,Y-2)`、`(8,Y-2)-(9,Y-2)`
**（9,Y）与（9,Y-1）不连**（玩家确认）

## 二、节点构成固定：6 类

命运所指×1、作战×1、紧急作战×1、不期而遇×1、安全的角落×1、得偿所愿×1 —— **无行商，且不随机。**

### 由此推出各构型的空地数

| 构型 | 格数 | 节点 | **空地** |
|---|---|---|---|
| 1 | 7 | 6 | **1** |
| 2 | 6 | 6 | **0** |
| 3 | 8 | 6 | **2** |

（玩家已确认：三种构型都是 6 个有效节点，多出来的都是空地）

### 现场怎么判断是哪一个构型、Y 是多少（实战流程）

1. **数格子**：右区一共几个格 → **7 = 构型1，6 = 构型2，8 = 构型3**。
2. **数空地小圆点**：1 / 0 / 2，与上表一致即为交叉验证。
3. **看左上角 y**：`(8,4)` / `(8,3)` / `(8,2)` 三档 → Y。**三层那局实测 Y=4**（右区占 y 2–4）。
4. **再点类型**：**2 个未知的凶戾 ＋ 3 个未知的诡秘 ＋ 1 个命运所指**。数量对不上 → 格子数读错了，重来。

> 2026-10-24 实例：8 格 + 2 空地 + 2 凶戾/3 诡秘/1 命运所指 → **构型3, Y=4**，与实机完全一致。
> 注意构型3 里 **`(9,Y)` 与 `(9,Y-1)` 不连**，命运所指就在 `(9,Y-1)` 上，别以为能顺着竖线走下来。

### 进层时能直接看到什么

因为「林间空地」始终可见、命运所指固定点亮：

| 看到的 | 实际是 | 数量 |
|---|---|---|
| 空地（地形） | 0 收益 | 0–2 格 |
| **明名「命运所指」** | 强制节点 | 1 |
| **未知的凶戾** | 作战 / 紧急作战 | **2** |
| **未知的诡秘** | 不期而遇 / 安全的角落 / 得偿所愿 | **3** |

**所以三层右区在进层那一刻信息就是完整的**——不需要探明就能规划，只有“哪个凶戾是紧急作战”要打了才知道（但两个都带 +16，所以不影响决策）。

## 三、进右区：必须“同 y 直线”

左区最右列 **x = 6**，右区最左列 **x = 8**，相隔 **正交 2 格**。

但右区会浮动（Y = 4 / 3 / 2），所以：

| 落点 | 必须先站到 | 可用道具 |
|---|---|---|
| (8,Y) | **(6,Y)** | 报废轮子（直线 2 格）、气垫底座（12 格）、方向盘（同行列） |
| (8,Y) 且站不到 (6,Y) | — | 只能任意跳（结构性原理 / 背包） |

**结论**：进右区前先确定 Y，再走到 **(6,Y)** 那一格直线跳过去。若 (6,Y) 不可达，就只能动用任意跳。

## 四、已确认（2026-10-24 玩家口径）

1. **右区节点类型固定、不随机**——上面那 6 类就是全部内容，进层即知（连"哪个凶戾是紧急作战"都不用猜：急1战1 是定数）。
2. **右区不会出现险路小径**（小径只长在左区）→ 右区的「未知的诡秘」= 不期而遇/安全的角落/得偿所愿，**100% 非负**。
3. 构型 1/2/3 靠**数格子**区分：7 / 6 / 8 格。
