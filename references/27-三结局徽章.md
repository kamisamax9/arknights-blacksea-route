# 白圈徽章：6 种字形与各自的定价 / 求解优先级（2026-10-30 玩家口径）

## 一句话

白圈徽章**文字里没有**，只能看像素；**同一个白圈压在不同节点 + 不同字形 = 完全不同的东西**。
识别靠 `pixel_probe.badge_glyph()` 的**灰度 NCC 模板匹配**（24×24、±6px 平移搜索、
rad±1，阈值 **0.55**），不是只看「有没有徽章」、也不是只看「宽/高」。
贴图标被合并的白块会在块内**再扫一遍字形**（`_glyph_scan`，含 ±2px 细扫）。

| 徽章字形 | 压在什么节点上 | 含义 | 价值 / 处理 |
|---|---|---|---|
| **骷髅面罩**（tears） | 不期而遇 | **泪之聚落**（三结局特殊事件） | **0 分**、默认不进、可作 0 分过路中继 |
| **蜘蛛**（informant） | 不期而遇 | **线人** | 二 4 / 三·四 10；五、六层没有 |
| **羊角骷髅**（ram） | 失与得 | 三结局特殊失与得 | **不变**（仍按普通失与得） |
| **狼头**（wolf） | 作战 / 普通作战 | **无效验尸** | **不变**（仍按普通作战） |
| **橡果**（acorn） | **任意节点** | **迷藏**（藏品标记） | **所在节点收益 + 12**（`rules.ACORN_VALUE`）；空地/密道/尽头**放行**，恶敌(全程追猎)/三·四层命运所指**不放行** |
| **乌鸦**（raven） | 空地 | 流窜居民（据点产物） | 不改类型（供 `resident_infer` 反推据点） |

> ⛔ 未收录字形 / NCC < 0.55 → **只提示、不改类型、不改价**，请玩家人工确认。
> 绝不硬猜：把「橡果」当线人会凭空 +10；把「乌鸦」当线人同样错。

## 三结局前置藏品已获取 → 每层 3 个带徽章节点

**已获取三结局前置收藏品**之后（可以是提前拿到的，例如二层「先行一步」），
**每一层**都会出现 3 个带白圈徽章的节点：

| # | 节点 | 变成什么 | 收益 |
|---|---|---|---|
| 1 | 失与得 ×1 | 三结局特殊失与得（羊角骷髅） | **不变**（三层 3） |
| 2 | 普通作战 ×1（地图写「作战」） | 「**无效验尸**」一战（狼头） | **不变**（三层左区 0） |
| 3 | 不期而遇 ×1 | 「**泪之聚落**」事件（骷髅面罩） | **0 分**（默认不进；可 0 分过路） |

- 五层的失与得可能不止一个，**只有带徽章的那个**是三结局特殊节点。
- **三结局前置藏品已获取 ⇒ 本层没有右区（熄日余径）**（玩家 2026-10-30 口径）；
  与 `25-右区有无.md` 的「只有四结局前置藏品才有右区」互为补充：两条线都不出现右区。

## 泪之聚落 vs 线人（最容易混的一对）

两者都是「不期而遇 + 白圈徽章」，文字完全一样，**只差字形**：

| | 泪之聚落 | 线人 |
|---|---|---|
| 字形 | **骷髅面罩**：窄、下端尖，像倒三角 | **蜘蛛/放射状**：多肢向四周伸开 |
| 实拍宽×高 | 15 × 21 | 21 × 22 |
| 宽/高（辅助校验） | **0.71** | **0.95** |
| 模板 | `glyph-tears.png` | `glyph-informant.png` |
| 价值 | **0**（三结局） | 二 4 / 三·四 10 |

- 实拍 NCC：同类 0.84–1.00（自匹配 1.00）、异类 0.1–0.4；五层 (3,2) 失与得的羊角贴着青色光晕，
  块内扫出 **0.96**（二值 IoU 只有 0.37，所以弃用了 IoU）。
- 固定标本（真实截图裁出的 24×24）：`tools/examples/glyph-*.png`；
  `selftest_solver` 的「徽章字形模板」用它们锁 6 种字形自匹配。
- **换分辨率/UI 改版后要重标**：跑 `python tools/label_ocr.py 截图 --layer N --badges`，
  看输出里 `（0.xx）` 是否仍然 ≥ 0.55；掉下去就把标本换成本局同名截图重裁。

## 迷藏（橡果）：**每格 +12 分，并入所在节点**（2026-10-30 新口径）

**效果**（玩家 2026-10-30 定）：进入新区域时标记一个节点 → 探索该节点获得**一件随机 SR 自然物**。
四件等概率，估值与动态如下：

| 自然物 | 估值 | 动态 |
|---|---|---|
| 光彩松露 | **32** 源石锭 | 无 |
| 恋家果 | **32** 源石锭 | 每次移动 **−2**（拿到就跌，越早卖越好） |
| 板藤 | **8** 源石锭 | 每次获得零件 **+4**（后面打得越多越值） |
| 旅行绒 | **1** 源石锭 | 每次移动 **+这次移动的曼哈顿距离**；**全图跳一次就 +10~17**（玩家 2026-10-30：实际不低于 32） |

### 量化：12 分

```
裸期望 = (8 + 32 + 32 + 1) / 4 = 18.25 源石锭
动态修正（拿到→卖给行商：m≈6–8 步、p≈3–5 个零件、总位移 D≈8–12 格）
  板藤 8+4p≈20–28 ／ 恋家果 32−2m≈16–20 ／ 光彩松露 32 ／ 旅行绒 1+D≈32–40
    （结构性原理/喷气背包/触须这类**全图跳一次就是 +10~17**，所以它实际不低于 32）
  → 期望 **≈25–30（中枢 26.5）**，比裸值高约 45%；涨的两项要「后面还有得打/还有得走」，
    所以**不额外加价**，取 25–30 这一档
折成求解器的「分」：本模型对大额奖励是**压平定价**的，不是 1:1
  树根 = 4 藏品（32 当量）+ 2 AP 只记 15（≈0.47 倍）；一层定点行商 +12 源石锭只记 4（0.33 倍）；
  1:1 只出现在小额段（1 件藏品 8 当量 = 得偿所愿 8；右区多 1 件高级藏品 = +16）
  按**树根锚点**折：25–30 当量 × 0.47 → **11.7–14.1（中枢 12.4）**
再扣实现折损：估值要走到行商才变现（五/六层行商必进、三/四层秘境行商必进，风险小），
  但占 1 个背包格 —— 与向上取整基本对冲
→ **ACORN_VALUE = 12**（真源 `tools/rules.py`，只在那处改数）
```

### 不变量（改数前先过一遍）

```
9  <  12  <  15  <  16 / 21
紧急作战 < 橡果 < 树根 < 右区作战 / 右区紧急
```

- 一件 SR 自然物**比一件随机藏品值钱** → 橡果 > 紧急作战 9；
- **4 件藏品 + 2 AP 仍是全场最高** → 橡果 < 树根 15；
- **右区多一件高级藏品** → 橡果 < 右区作战。
- 推论：橡果压在不期而遇(9)/得偿所愿(8) 上 = 21/20，压在诡秘(5) 上 = 17，
  压在**空地**上 = **12**——这些位置才是它该待的地方（高于普通节点、低于树根）。

### 求解口径（三条，都要照做）

1. **相加，不替换**：橡果节点的收益 = **所在节点收益 + 12**。
   实现是 scenario 的 `"cell_values": {"x,y": 分}`（逐格覆盖，优先于类型价），
   求解器里 pval / 走法 / fmt 打印全部走 `Solver.cell_value()` —— 打印分与总分永远对得上。
2. **原本是墙的格子，带橡果要按类型分别处理**（见下表）：放行的写进
   `"block_except": [[x,y]]`，地基按 **0** 起算（`rules.acorn_base_value` 把 -99 墙标记视作 0），
   所以「空地 / 密道 / 尽头」带橡果 = **12 分**，可以正式进路线规划。
3. **`"acorn"` 列表保留**，只用于：① 判词里报「本条经过几个橡果」；② 兜底——
   手写 scenario 只写 `acorn` 没写 `cell_values` 时，求解器按 `rules.acorn_value()` 补 +12。

> ⛔ 不要再退回旧口径「不改价 + 同分优先（`ACORN_EPS`）」：那等于「愿意为它少拿 1 分」，
> 与玩家现行口径冲突。`ACORN_EPS` 已从代码删除。
> ⛔ 也**不要**把橡果当必走点（`must`）：本层拿不到（压在禁踩格上）时如实打 ⚠️，
> 别为它锁死路线。

### 哪些格子带橡果能放行（玩家 2026-10-30 逐条口径，`rules.ACORN_PASS_TYPES` 是真源）

| 节点 | 带橡果 | 做法 |
|---|---|---|
| 林间空地 | **放行** | 0 → **12 分**；三层起的硬墙对它豁免 |
| 曲折密道 | **放行** | 0 → **12 分**；**必须写 `portals`（强制传送）**：踩 A 落 B，图上两格**只结算一次**（求解器把两端 bit 一起置位）。配对不确定（密道格 ≠ 2 个）时**不放行**并提示玩家报另一端坐标 |
| 险路尽头 | **放行** | 全程追猎：0 → **12 分**，可当**中继**。险路尽头模式：**降级为软终点**（`final_soft_types`，可当中继、停这里也合法收尾），但**建议直接把它留给最后一步**——省下的行动力就是收益（玩家原话） |
| 险路小径 | 本来就放行 | 0 → **12 分**；险路尽头模式下同上（同样降为软终点） |
| **险路恶敌** | **全程追猎：不放行** | 仍 block（玩家口径：「不放行，不进入」）。**险路尽头模式**：它本来就是最后一步，照常走、+12 不改变结论 |
| **命运所指**（三/四层） | **不放行** | 玩家口径：即使带橡果也不进（五层它是终点，本来就能进） |

- **密道的打印**：路径里存的是**落点**，所以 `fmt` 会补一句「← 踩 (a,b) 强制传送」，
  否则玩家会看到「从 (6,3) 走到 (0,0)」这种没法执行的指令。
- 二层例外：那里尽头/小径是 8 分（四结局道具），**不降级**（否则「尽头 8 + 小径 8」会重复计）；
  判据在 `build_scenario.acorn_soft_final_types()`：**该类型基础价必须为 0**。

### 压在禁踩格上怎么办（恶敌 / 命运所指）

「不放行」的两类（**险路恶敌**在全程追猎、三·四层**命运所指**）上带橡果 → **这一层迷藏吃不到**：
`route.py` / `build_scenario.py` 打一条 ⚠️ 如实说明（`acorn_wasted_cells()`），不许静默也不许硬绕。
要破例必须玩家明确同意，别自己改 `block`。

```bash
# 看徽章 + 字形（三/四/五层自动判有没有右区，不再硬套 11/12/14 列）
python tools/label_ocr.py 截图 --cols 8 --rows 5 --layer 4 --badges
```

正常管线（`board_read` / `grab --scene` / `route.py` / `build_scenario.py`）**已经自动检测**。
2026-10-30 四层实拍（构型 L8、无右区）输出示例：

```
徽章：(3,3) 作战 + 狼头徽章（0.875）→ **无效验尸**（收益同普通作战，不改价）
徽章：(4,3) 不期而遇 + 骷髅面罩（0.84）→ **泪之聚落**：0 分、默认不进，可作 0 分过路中继
徽章：(6,2) 空地 + 乌鸦徽章（1.0）→ 流窜居民（据点产物，不改节点类型）
徽章：(3,1) 失与得 + 羊角骷髅徽章（0.839）→ 三结局特殊失与得（**收益不变**）
```

2026-10-30 **五层实拍**（构型 L8、9 列无右区）：4 枚徽章 = (3,2) 失与得羊角 **0.96** +
(2,3)/(7,2)/(8,2) 三枚乌鸦 0.90–0.98；**没有**狼头/骷髅徽章（所有「作战」都是普通作战，
且本层没有「不期而遇」标签——若这两个特殊节点还没探明，它们的徽章可能不显示）。

节点表里会直接写 `泪之聚落` / `不期而遇线人`，规划按改写后的类型取价；
橡果写进 `acorn` 列表并打印「迷藏（橡果）：… → 收益 +12 并入所在节点（带橡果的空地放行）」。

| `tools/label_ocr.py` | `apply_badges()` 按「节点类型 + 字形」翻译；`--badges` 自动按格点宽度定列 |

| `tools/route_solver.py` | 认 `cell_values`（逐格覆盖）、`block_except`（逐格豁免 block）、`portals`（强制传送，两端 bit 一起置位=只结算一次）、`final_soft_types`（软终点）；`Solver.cell_value()` 统一 pval/走法/fmt；**`ACORN_EPS` 已删除** |
| `tools/selftest_solver.py` | 6 种字形自匹配 + 合并块检出 + 迷藏「+12 并入节点 / 空地放行 / 兜底」三组断言 |
| `tools/examples/glyph-*.png` | 6 个 24×24 字形标本（真实截图裁出，改 UI 要重裁） |
| `tools/examples/badge-merged-gain.png` | 五层 (3,2) 合并块标本（羊角贴着失与得光晕），锁「块内扫」 |

## 常见错误

| 错误 | 后果 | 正确判据 |
|---|---|---|
| 只按「有徽章」判类型 | 把橡果/乌鸦/羊角都当线人，凭空 +10 | 必须做**字形 NCC 匹配**，未收录就只提示 |
| 用「宽/高」硬判所有徽章 | 羊角、狼头、橡果、乌鸦都落在 0.9–1.05，互相误判 | 宽/高只作辅助；主判据是 NCC |
| 无右区 7/8/10 列截图按 11/12/14 列映射 | 徽章全部映射到错格 | `--badges` 自动定列；手传时列数必须对 |
| 只认「方正白块」 | 贴图标的徽章被合并成 44×30 大块 → 五层 (3,2) 羊角漏检 | 合并块也在块内扫字形（`_glyph_scan`） |
| 用 `is_resident` 色度闸判徽章 | 红/彩色背景上的乌鸦被拒 → 五层 (2,3) 漏检 | 徽章判定只认「有字形 + NCC」；色度闸只留给居民 |
| 把带徽章的失与得/无效验尸重新估值 | 与玩家口径冲突 | **收益不变** |
| 给泪之聚落 block 掉 | 唯一通路经过它时要多绕 1–2 步，或判无解 | 0 分但**可过路**，不 block |
| 迷藏按「不改价、同分优先」算（旧口径） | 等于「愿意为它少拿 1 分」，橡果空地永远排不进路线 | **+12 并入所在节点**；空地/密道/尽头靠 `block_except` 放行 |
| 带橡果的密道只加价、不写 `portals` | 求解器以为能从密道原地走出去 → 路线的下一跳全是错的 | 必写 `portals`；两端同价 + 两端 bit 一起置位（一次结算） |
| 二层也把带橡果的尽头/小径降成软终点 | 「尽头 8 + 小径 8」重复计 16 | 只在**基础价为 0** 时降级（`acorn_soft_final_types`） |
| 把带橡果的险路恶敌（全程追猎）放行 | 玩家口径是「不放行、不进入」 | 恶敌永远在 `ACORN_STAY_BLOCKED` 里 |
| 把橡果写进 `must` | 压在禁踩格上会判「无可行解/必走点走不到」 | 只加价值；拿不到就 ⚠️ 如实报 |
| 带橡果的空地按 `-99 + 12` 算 | 变成 -87 分，等于没放行 | 地基走 `rules.acorn_base_value()`（墙标记按 0） |
| 换分辨率后沿用旧标本 | NCC 掉下去，误判 | 重跑 `--badges` 看匹配分，必要时重裁标本 |
